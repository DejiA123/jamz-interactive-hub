# Gospel Jamz Interactive Event App

## Experience
- Build the selected Magazine Broadcast visual direction with the locked celestial-stage palette and event details.
- Make the first screen an attendee hub: enter a six-digit code, view live activity, answer a sample quiz, add to a word cloud, and see scores.
- Add a Host Studio where the organiser can create, edit, launch, and close quizzes, polls, word clouds, ratings, and audience challenges.
- Add a joined-session view with participant nickname entry, timed questions, results, and leaderboard states.

## Live event foundation
- Enable Lovable Cloud for persistent sessions, questions, responses, participants, and join codes.
- Protect host controls behind sign-in and keep attendee joining frictionless.
- Use live updates so host changes, audience answers, results, and scores appear during an active session.
- Include a ready-to-try Gospel Jamz demo session and content in the initial data.

## Visual and interaction details
- Follow the chosen magazine grid exactly: masthead, dominant join-code strip, schedule ticker, live word cloud, quiz, editorial image, leaderboard, host panel, and challenge.
- Use Archivo Black and Hind, chrome-like edges, cyan/gold stage light, crisp button feedback, and restrained ticker/count motion.
- Generate the stage photograph required by the selected direction rather than shipping a placeholder.
- Adapt the interface for phones and desktop, with accessible controls and reduced-motion support.

## Verification
- Check the attendee join flow, sample interactions, host creation flow, live updates, metadata, and error states.
- Review the final result at desktop and mobile sizes for readability and overlap.
